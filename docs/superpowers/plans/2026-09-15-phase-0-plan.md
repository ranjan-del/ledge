# Ledge phase 0 implementation plan

Spec: `docs/superpowers/specs/2026-09-14-ledge-design.md`. Read it first.
Date: 2026-09-15. Repo: `~/AI/ledge`, branch `main`, npm workspaces monorepo.

Five work packages run in parallel, each owning one folder. Nobody edits another
package's folder. Shared contracts below are fixed; if a contract must change, stop
and report instead of changing it.

## Monorepo layout (final for phase 0)

```
ledge/
  package.json                 npm workspaces: packages/*, apps/*   (exists, do not edit)
  tsconfig.base.json           shared TS options                    (exists, do not edit)
  packages/core/               @ledge/core   shared logic, zero runtime deps except `yaml`
  packages/cli/                @ledge/cli    the `ledge` binary, depends on @ledge/core
  apps/desktop/                Tauri 2 + Svelte 5 app, depends on @ledge/core
  plugin/                      Claude Code plugin (no build)
  .claude-plugin/marketplace.json   so `/plugin marketplace add ranjan-del/ledge` works
  docs/                        getting-started, architecture, adr/, manual-qa
  .github/                     CI, release, templates
  README, CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, ROADMAP, CHANGELOG, NOTICE
```

## Conventions

- Node >= 22.6, TypeScript source run directly by Node (type stripping). No build
  step for core and cli. `erasableSyntaxOnly` is on: no enums, no parameter
  properties, no namespaces. Use `import type` for types.
- Tests: Node's built-in runner, `node --test test/*.test.ts`. No test frameworks.
- Each package has `package.json` with `"type": "module"`, scripts `test` and
  `typecheck` (`tsc -p tsconfig.json`), and a `tsconfig.json` that extends
  `../../tsconfig.base.json`.
- Imports inside a package use relative paths with `.ts` extensions.
- Cross-package import is `@ledge/core` only (workspace link). Never deep-import.
- Line width 100. No em dashes anywhere, in code comments or docs.
- Every exported function has a one-paragraph doc comment saying what it does and
  why it exists.
- Never write outside `LEDGE_HOME` (tests set it to a temp dir).

## Contract 1: task file format

See spec section 2. Filename `YYYY-MM-DD-<id>.md` where the date is `created`.
Frontmatter keys: `id title status order repo sessions created updated parked`.
Body headings `## Requirement` and `## Checklist`. Unknown body text after the
checklist is preserved verbatim in `extra`.

## Contract 2: @ledge/core public API (`packages/core/src/index.ts`)

```ts
export type TaskStatus = 'current' | 'backlog' | 'done';

export interface ChecklistItem { text: string; done: boolean }

export interface Task {
  id: string;
  title: string;
  status: TaskStatus;
  order: number;
  repo?: string;              // absolute path, `~` expanded on load, re-tilded on save
  sessions: string[];
  created: string;            // ISO 8601 with offset
  updated: string;
  parked?: string;
  requirement: string;        // markdown under ## Requirement, trimmed
  checklist: ChecklistItem[];
  extra: string;              // anything after the checklist, trimmed
  file: string;               // absolute path of the .md file, '' when unsaved
}

export interface Config {
  roots: string[];
  scan: { intervalMinutes: number; maxDepth: number; ignore: string[]; staleDays: number };
  terminal: string;
  claude: { command: string; resumeFlag: string };
  ui: { edge: 'left' | 'right'; theme: 'system' | 'light' | 'dark'; y?: number };
}

export class TaskParseError extends Error { file: string; line?: number }

export function ledgeHome(): string;                 // $LEDGE_HOME or ~/.ledge
export function defaultConfig(): Config;
export function loadConfig(home?: string): Config;   // deep-merges defaults, never writes
export function saveConfig(config: Config, home?: string): void;

export function parseTask(markdown: string, file?: string): Task;   // throws TaskParseError
export function serializeTask(task: Task): string;                  // round-trips parseTask
export function slugify(title: string): string;
export function taskFileName(task: Pick<Task, 'id' | 'created'>): string;

export class TaskStore {
  constructor(home?: string);
  readonly home: string;
  init(): { created: boolean };                       // makes dirs, default config, sample task
  list(status?: TaskStatus): Task[];                  // tasks/ only, sorted by order then updated desc
  archived(): Task[];                                 // archive/ only
  get(id: string): Task;                              // throws if missing
  add(input: { title: string; repo?: string; status?: TaskStatus; requirement?: string }): Task;
  start(id: string): Task;                            // status current, order 1, others shift
  park(id: string, reason: string): Task;             // status backlog
  done(id: string): Task;                             // status done, file moved to archive/
  link(id: string, sessionId: string): Task;          // append if absent
  addTodo(id: string, text: string): Task;
  setTodo(id: string, index: number, done: boolean): Task;
  reorder(status: TaskStatus, ids: string[]): void;   // rewrite order 1..n
  currentFor(cwd: string): Task | undefined;          // deepest repo match among current tasks
  save(task: Task): Task;                             // bumps updated, writes file
}

export function matchRepo<T extends { repo?: string }>(tasks: T[], cwd: string): T | undefined;

export interface RepoStatus {
  repo: string;               // absolute path
  branch: string;
  upstream?: string;
  ahead: number;
  behind: number;
  dirty: { path: string; code: string }[];   // porcelain v2 XY code
  lastActivity: string;       // ISO, from .git/index mtime
}

export function parsePorcelainV2(output: string, repo: string, lastActivity: string): RepoStatus;
export function findRepos(roots: string[], maxDepth: number, ignore: string[]): string[];
export function scanRepos(config: Config, opts?: { referenced?: string[]; now?: Date }): Promise<RepoStatus[]>;
export function isPending(status: RepoStatus): boolean;  // dirty, ahead > 0, or no upstream on non-main branch

export function buildResumePrompt(task: Task): string;   // title, requirement, unchecked items
```

Dependencies allowed in core: `yaml` (runtime), `@types/node` and `typescript` (dev).

## Contract 3: `ledge` CLI surface (`packages/cli`)

Binary name `ledge`, entry `packages/cli/bin/ledge.ts` with a `#!/usr/bin/env node`
shebang (Node strips types). Commands exactly as spec section 4 plus:

- `ledge --json` on any listing command prints JSON instead of text.
- `ledge current --repo <path> [--json|--context]`. `--context` prints the block the
  SessionStart hook injects: title, requirement, unchecked items, max 40 lines.
- `ledge todo <id> "text"` and `ledge tick <id> <n>` / `ledge untick <id> <n>` (1-based).
- `ledge open <id>` prints the task file path (used by the plugin to hand Claude the file).
- Exit codes: 0 ok, 1 usage error, 2 not found, 3 parse error (prints file and line).
- No colour libraries. Plain text, aligned with spaces.

## Contract 4: plugin (`plugin/`)

- `plugin/.claude-plugin/plugin.json`: name `ledge`, version `0.1.0`, description,
  author, homepage, license MIT.
- `plugin/commands/ledge.md`: the `/ledge` command with subcommands start, park,
  done, todo, and bare. Frontmatter `description` and `argument-hint`. Body tells
  Claude the exact file format (copy from spec section 2), the CLI commands to call,
  and the rule to tick checklist items as steps finish.
- `plugin/hooks/hooks.json` wiring SessionStart, Stop, PreCompact to the three
  scripts with 5 s timeouts. Scripts are POSIX sh, read JSON payload from stdin,
  use `cwd` and `session_id` fields, call `ledge`, always exit 0, print nothing on
  error. If `ledge` is not on PATH print one hint line on SessionStart only.
- `plugin/README.md`: install, what each hook does, token cost, uninstall.
- `plugin/test/hooks.test.sh`: feeds fixture payloads, asserts output; runs with a
  fake `ledge` on PATH so it needs no real store.
- Root `.claude-plugin/marketplace.json` listing the plugin at `./plugin`.

## Contract 5: desktop app (`apps/desktop`)

Tauri 2, Svelte 5 (runes), Vite, TypeScript. Vitest for UI tests only here. Rust
cannot be compiled on the build machine yet (no toolchain), so Rust code must be
written carefully, kept minimal, and follow the Tauri 2 API exactly; `cargo check`
runs in CI.

Rust side (`src-tauri/`): two windows declared in `tauri.conf.json`, `button`
(48x48, transparent, decorations false, always on top, skip taskbar, resizable
false) and `panel` (380x720, transparent, decorations false, hidden at start).
Plugins: `tauri-plugin-fs` (read, write, watch under `$HOME/.ledge`), `tauri-plugin-shell`
(git and terminal), `tauri-plugin-os`, `window-vibrancy` (macOS `Sidebar` material,
Windows Mica with Acrylic fallback). Commands: `toggle_panel`, `snap_button(edge, y)`,
`open_terminal(dir, command)` (macOS via `osascript` and Terminal.app, Windows via
`wt`, Linux via `x-terminal-emulator`). Nothing else in Rust.

Web side (`src/`): imports `@ledge/core` for parsing, serialization, porcelain
parsing, prompt building. File IO through the fs plugin. Git through the shell
plugin running `git -C <repo> status --porcelain=v2 --branch`. Store in a Svelte
rune module `lib/store.svelte.ts`. Components: `Button.svelte`, `Panel.svelte`,
`Tabs.svelte`, `TaskRow.svelte`, `TaskDetail.svelte`, `PendingRow.svelte`,
`Agenda.svelte` (stub, hidden), `Settings.svelte`. Design tokens in `src/styles/tokens.css`
with per-platform overrides via a `data-os` attribute on `html`. System font stack.
Dark and light follow `prefers-color-scheme`. Every list re-renders only the
changed task. Poll nothing: rely on fs watch plus the scan interval.

Low resource rules: no animation loops when the panel is hidden, scan interval
default 5 min, debounce watch 150 ms, git runs with a concurrency limit of 4,
repos stale > `staleDays` skipped unless referenced by a task.

## Contract 6: docs and community files (root, `docs/`, `.github/`)

Mirror the RagFabric repo style (`~/AI/ragfabric`): centered header with badges,
honest status paragraph that claims nothing unshipped, table of contents,
technology stack table, installation, configuration, repository layout, what works
today, limitations, roadmap, contributing, license. Files: README (rewrite),
CONTRIBUTING, CODE_OF_CONDUCT (Contributor Covenant 2.1), SECURITY, ROADMAP,
CHANGELOG (Keep a Changelog), NOTICE. `docs/README.md`, `docs/getting-started.md`,
`docs/architecture.md`, `docs/task-file-format.md`, `docs/configuration.md`,
`docs/manual-qa.md`, `docs/adr/0001-plain-files-not-a-database.md`,
`docs/adr/0002-tauri-over-electron.md`, `docs/adr/0003-no-claude-mem-read.md`.
`.github/`: `workflows/ci.yml` (npm test and typecheck on Node 22 and 24, plus
`cargo check` in `apps/desktop/src-tauri` on ubuntu, macos, windows),
`workflows/release.yml` (tauri-action on `v*` tags), `ISSUE_TEMPLATE/bug_report.yml`,
`ISSUE_TEMPLATE/feature_request.yml`, `ISSUE_TEMPLATE/config.yml`,
`PULL_REQUEST_TEMPLATE.md`, `dependabot.yml`, `CODEOWNERS` (`@ranjan-del`).
